# Add Ticket to Project Board

Create a new GitHub issue and add it to the Spam Project Board.

## Your Task:

1. Ask the user for the ticket details if not already provided:
   - Title (required)
   - Description/Body (required)
   - Labels (optional, comma-separated like "frontend,auth0")
   - Priority (optional, like "P1", "P2", "P3")
   - Size (optional, like "S", "M", "L")

2. Create the GitHub issue using `gh issue create`

3. Add the created issue to the "Spam Project Board" (project ID: 15, owner: ngahuru-2025)

4. Optionally ask if the user wants to add this ticket to the `.github/tickets.md` file for documentation

5. Report back with the issue number and URL
